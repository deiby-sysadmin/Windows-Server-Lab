# Índice general del laboratorio

Este documento sirve como índice principal de toda la documentación generada durante el laboratorio de Windows Server. Desde aquí se puede acceder a cada una de las secciones y materiales creados durante el proyecto.

## Contenido del laboratorio

- **01-Infraestructura**  
  Configuración inicial del entorno, máquinas virtuales y red.

- **02-Active-Directory**  
  Instalación del dominio, usuarios, grupos y OU.

- **03-GPOs**  
  Políticas de grupo aplicadas en el entorno.

- **04-Seguridad**  
  Medidas de seguridad implementadas en el dominio.

- **05-Automatización**  
  Scripts y tareas automatizadas del laboratorio.

- **06-Servicios**  
  DNS, DHCP, NTP, comparticiones SMB, impresión y WSUS.

- **07-Monitorización**  
  Supervisión del dominio mediante herramientas del sistema.

- **08-Documentación**  
  Material final del laboratorio:
  - Apuntes técnicos
  - Capturas del entorno
  - Manual técnico completo

## Objetivo de este índice

Facilitar la navegación y consulta de toda la documentación del laboratorio, ofreciendo una visión clara y estructurada del trabajo realizado.
