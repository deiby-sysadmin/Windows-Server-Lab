# Auditorías del servidor

Esta sección documenta la configuración de auditorías en el servidor Windows, utilizadas para registrar eventos críticos como inicios de sesión, accesos a recursos, modificaciones en objetos del sistema y actividades administrativas. Las auditorías permiten detectar comportamientos sospechosos, mejorar la trazabilidad y reforzar la seguridad del entorno.

## Objetivo de esta sección

Implementar un sistema de auditoría que permita supervisar acciones relevantes dentro del servidor y del dominio, garantizando que cualquier actividad importante quede registrada para su análisis posterior.
