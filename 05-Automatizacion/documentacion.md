# Automatización del entorno

En esta sección se documentan los scripts y herramientas utilizados para automatizar tareas dentro del laboratorio Windows Server. La automatización permite reducir errores, acelerar procesos y mantener configuraciones consistentes en el dominio.

## Contenido de esta sección

- Scripts PowerShell para administración del dominio
- Scripts de backup para copias de seguridad automatizadas
- Ejecución programada mediante tareas programadas
